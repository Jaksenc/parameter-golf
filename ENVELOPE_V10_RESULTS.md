## Implemented mechanism

Retain supported structural and opaque-name readings of coordination in relational complements, plus alternative scopes of unmarked negated coordination. Fully enumerate the bounded interpretation set; solve each with the existing monadic kernel and check each certificate with its separate Boolean checker. Return a label only if all represented readings agree. Unsupported syntax or overflow abstains; a truncated interpretation set cannot answer.

When readings disagree, return competing checked interpretations and the minimum number of clause-reading selections sufficient to distinguish opposite-verdict theories. The implementation uses a finite covering problem; the independent audit checks answer buckets and all smaller subsets. This is minimum among the available clause-reading questions for the current envelope, not the globally optimal English question or a guarantee every intended reading is represented.

Among55 ambiguous sources,52 require one clause-reading selection and3 require two. Independent bucketing verifies all55 minima and128 resulting answer buckets. A question may offer multiple readings; these are not necessarily binary questions. The full primary experiment separately checks1043 formal interpretations. Grammar interpretation remains a shared trust boundary.

Caller-supplied atom declarations protect complete predicate phrases consistently across occurrences. They are explicitly additional semantic assumptions, not an inferred fact or an answer key. Default CLI accepts formal input. English requires --experimental-english and is not promoted as a universally trusted verifier.

## Decision

This is a reliability/coverage tradeoff and an explicit interpretation-resolution interface, not a general Jev upgrade. Under a simple constant-cost model, withholding55 answers to avoid2 observed wrong answers is advantageous only if error cost exceeds27.5 times clarification cost, before considering subsequent answers. That is arithmetic on this finite sample, not a production loss estimate. Intended readings may still be absent from the envelope; consensus cannot prove their inclusion. Independent per-clause possibilities can also cause unnecessary abstention when repeated meanings should be linked.
