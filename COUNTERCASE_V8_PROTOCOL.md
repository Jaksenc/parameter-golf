# Countercase v8 — protocol fixed before model outcomes

Primary: countercase480, one uninterrupted generation from a fixed counterexample-guided system prompt. Pin entity, time, quantifier and polarity; construct needed computation; attempt to rule out the leading answer and strongest rival without changing explicit evidence. Distinguish contradiction from insufficient support, and possible countermodels from actual events. A typed source-plus-draft fallback is used only when the same strict FINAL parser used in v7 cannot find a completed allowed answer. No second generator, judge, confidence gate, ensemble, model training, or oracle.

Comparison: standard480, the exact v7 480-token ordinary-reasoning prompt and categorical fallback. Same canonical user evidence, frozen Qwen3.5-4B weights, greedy decoding and 480 output-token ceiling. System prompt and actual output length differ, so equal ceilings are not equal computation. The new primary alone is the tested method; there is no benchmark-selected alternative. Hypothetical cases in the draft are not independently verified proof certificates.

Population: all 231 reused public JevBench items from benchmark commit 7128f5cf445ca41e4da1bdc7c84f97926250724d, plus 64 new-to-project BBH examples, eight from each of the same eight v7 families. Sources are pinned BBH commit 9ee07bd481feebf959a6b59d61ea57bdcf30964d. Selection seed 820260921; normalized input-stem exclusions include all 421 prior v6 inputs and all 295 v7 inputs, including every v7 external case. Selection is independent of targets; correct-label mapping is validated afterward. Public BBH pretraining contamination remains unknown. This is an eight-family sample, not the full BBH benchmark or a private holdout.

Public standard480 observations are reused intact from v7 (202/231), not regenerated for free. The primary is newly inferred on every public input. Both arms run live on all 64 new external inputs, with deterministic randomized call order on each item. Every worker verifies fixed model-weight hashes, full/restricted projection fixture and a saved native anchor. Public latency comparisons are cross-run descriptive; external latency comparisons are within-run paired phase sums. No production-speed claim from free CPU timings.

Total: 295 unique inputs, 359 new generation slots, 231 preserved standard outputs. Jobs include only id/state/question/labels and required arms; no targets, old answers, scores or task-family metadata. Output rows flush and fsync after each complete matched item. Incomplete tasks remain explicit. Recovery, if necessary, may rerun only unavailable complete rows and must preserve all complete originals; outcomes cannot select repairs or omissions.

Endpoints: primary paired accuracy versus standard480, separately on public and new BBH. Publish per-task labels, repairs/regressions, source-group bootstrap for public (195 groups), family-stratified paired item bootstrap for external, exact discordant-pair tests, actual generated tokens and time. Intervals are exploratory, not adjusted for repeated benchmark reuse or multiple comparisons. No invented calibrated probability vectors for generated labels. Any candidate-union ceiling is retrospective and must not be called achieved performance.

Mechanism diagnostic fixed now: among public items for which BOTH v7 base long320 and blind160 were incorrect, count new correct answers, and report all new regressions versus standard480. Also report the oracle union of the same frozen candidate sets. Do not retrofit a switching rule based on this test. Review paired examples for supported and hallucinated counterexamples without treating answer correctness as trace correctness.

Preflight: 36 local unit tests passed, covering schema, evidence identity, fallback behavior, candidate selection and target-independent inclusion.
