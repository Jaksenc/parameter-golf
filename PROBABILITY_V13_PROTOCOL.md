# Probability v13 — fixed protocol, September 22, 2026

Objective: establish the missing probability-returning baseline before weight training. Primary is ordinary480 reasoning followed unconditionally by the existing Handoff all-option readout, including when the draft has a completed FINAL label. The primary answer is the actual distribution argmax; it must not inherit the old textual-answer score. Model and prompts are pinned, not optimized on new outcomes.

Population: all 231 reused public JevBench inputs; all 64 historical v7 BBH inputs; 73 source inputs for temperature fitting (the deduplicated v1 development split); and 73 disjoint source-check inputs (the v1 calibration split). All are historical datasets; the new readout observations are new. This is not an untouched confirmation corpus. Exact canonical input disjointness is checked across all 441 tasks. No Jev API calls, backbone training, benchmark-key distillation, official submission or main-branch changes.

Measured paths: new native logits on all 441 inputs; new full-draft logits on all 441; new logits after removing only explicit FINAL lines on all 441. The latter is a diagnostic for explicit answer anchoring, not proof of removing every answer cue and not a retroactively selectable primary. Each readout includes original evidence. Readout order is deterministically randomized per input. The same 295 archived ordinary480 drafts are reused without changes. The 146 source drafts are newly generated with the unchanged ordinary prompt and 480-token maximum. The old 295 textual-answer outputs remain accuracy-only controls.

Calibration: fit one positive scalar temperature separately for native, full and masked paths, using only the 73 calibration-fit records and preserving soft targets. Fixed grid T=2^(i/32), i=-64,...,96, includes identity and covers [0.25,8]. Minimize mean target cross-entropy; tie-break toward identity. Save fitted parameters and fitting-record hashes before test metric reduction. No test-selected temperature, prompt, routing threshold, ensemble or arm. Report raw and calibrated results, parameter-boundary hits, source-check outcomes, calibration uncertainty and domain-shift limits. The 301 earlier source training records are not used in this experiment. Fitting temperatures is not updating model weights.

Primary endpoints: argmax accuracy and paired repairs/regressions versus ordinary text answers; target-distribution log loss and Brier score versus separately calibrated native inference. Report ten-bin ECE descriptively, and exact-distribution TVD on the ten public probability items separately. Target cross-entropy uses provided distributions, not modal one-hot labels. Public uncertainty uses 195 source groups; BBH uses paired item resampling within eight families; source check is item-resampled within source. These finite-sample exploratory intervals do not correct for repeated benchmark reuse or pretraining exposure. No full 534-decision composite without missing tiers, comparable price and serving data.

Every output path must supply measured finite logits for every allowed label. Do not manufacture one-hot confidence or retain a textual answer inconsistent with reported probabilities. Score expected levels and binary values are derived from that vector. A concentration statistic is not correctness probability. Unfinished drafts are retained and measured, not removed from denominators.

Compute: all 441 direct passes and 882 readout passes are measured in this run; 146 source generations are live. For 295 historical evaluation items, combined reasoning/readout cost uses archived generation plus new readout and must be labeled cross-run phase accounting, not an integrated latency measurement. Direct screening is not part of the primary slow policy and must not be charged to that policy merely because the experiment ran it. No KV reuse or GPU/production speed claim. Account for actual tokens and prompt prefill, not maximum-token ratios. Retain failed/incomplete work; any recovery selects only unavailable complete records.

Pre-inference checks: 34 unit tests passed, including unconditional readout on completed FINAL, masked-line behavior, strict probability boundaries, soft target preservation, and rejection of evaluation records from scalar fitting. Pretrained Qwen/Qwen3.5-4B revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a; unchanged CPU BF16 backbone/FP32 selected-code projection. Each worker verifies model-weight hashes, native anchor and restricted/full projection fixture. All recomputed native rows and old fallback vectors will be compared after completion.
