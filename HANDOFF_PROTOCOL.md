# Handoff v5 — pre-outcome protocol, September 21, 2026

Primary arm: handoff64. Preserve a complete valid FINAL answer within the first 64 draft tokens; otherwise force a typed categorical answer using that prefix and the original evidence. The output is an argmax over unique single-token decision codes, not an unbounded generated string. Source weights stay frozen; no training, Jev inference, oracle answer lookup or benchmark-label access during inference.

Main reference: completed Evidence v4 short-reasoning control (160-token cap with its original native fallback). Main goal is bounded-token answer reliability and accuracy; no speedup is assumed. Other controls: original native, same final-readout prompt with no draft, same prompt with length-matched neutral placeholder, forced typed readout for every 64-token prefix, forced typed readout for the full archived draft, and preserve-or-recover handoff at 160. Every arm is reported. Primary and 64-token budget are fixed, not selected on evaluation outcomes. No retroactive promotion of an alternative arm.

Data: all 231 pinned public JevBench cases, all 64 previously evaluated English cases, and 64 new paired policy probes: receipt/entity binding, strict/inclusive deadline, overriding exception, every-versus-at-least-one quantification. New set has 32 pairs, each differing in one operative fact or rule and flipping the oracle label; common numerical parameters stay fixed. Labels are generated separately and excluded from prompts. This is a narrow authored stress test, not an external broad benchmark. Existing public cases and 64 English cases are reused and were inspected previously. No full hidden leaderboard, production cost, calibrated probabilities, or submission is claimed.

The 295 old reasoning texts are replayed from the unchanged completed v4 archive. They are retokenized and truncated; original generated token IDs and KV caches were not saved. Therefore this is a context-replay experiment, not an exact cached-interruption replay. All prefix IDs, draft hashes, readout prompts, logits and timings are recorded. The 64 new probes generate one live 160-token greedy trace with real token IDs and wall-clock taps at 32/64/160. This makes prefix-cost measurements possible on the fresh set without multiplying draft samples. Four readouts per case are executed in a deterministic per-case shuffled order. Readouts re-prefill the full source; no KV optimization is claimed.

Length-matched neutral text is a control for added text and rereading; it is not exactly FLOP-matched across token re-encoding or different tokenization boundaries. Prefix analyses use only the actual permitted prefix. Final-label parsing rejects potentially truncated label prefixes. The historical comparator retains the historical parser rather than silently changing its score. Typed probabilities are raw, conditional, uncalibrated softmax outputs; do not call them calibrated confidence or create synthetic distributions for hybrid labels.

Paired accuracy and NLL/Brier only where meaningful. Compare primary to the stronger reasoning baseline, not only native. Accuracy uncertainty: paired source-group resampling for public JevBench; paired group resampling across 32 fresh policy pairs. Report both-cases-correct pair rate and simple answer-flip rate separately: flipping answers is not proof of truth. Missing inference is an execution failure, never a dropped benchmark item. Reuse completed records on recovery without task or prompt changes.

Scope: project-specific engineering and controlled evaluation. Budget forcing and forced-final early exiting have prior art: s1 (arXiv:2501.19393), Entropy After </Think> (arXiv:2509.26522). We do not claim literature-wide novelty, recovered Jev architecture/RLCD, or a new trained model.
