# Resume v6 — protocol before new inference, September 21, 2026

Primary: resume_complete. At the existing 160-token draft boundary, preserve a strictly complete allowed FINAL answer. Otherwise, resume that assistant draft with the same original prompt for at most 160 additional greedy tokens, stopping at a newline-terminated exact FINAL or EOS. If still incomplete, use the unchanged Handoff v5 source-plus-draft categorical readout. No confidence thresholds, answer-based routing, model training, or alternative-primary selection.

This follows the failed v5 early interruption result. It does not assert that punctuation certifies semantic completeness. It tests whether unfinished generation should continue as generation instead of becoming a fixed provisional document supplied to a new reader.

Controls: native direct readout; old 160-token reasoning/native fallback; Handoff160; continuation with native fallback; causal lexical rollback followed by continuation; causal lexical rollback followed immediately by the unchanged typed readout. Rollback discards at most 32 retokenized tokens to the last sentence punctuation/newline visible in the current draft. Rollback is a secondary ablation, not a new reasoning correctness verifier. The two continuation branches use equal additional token ceilings, not equal actual tokens, retained-prefix lengths, or FLOPs. Branch execution order is randomized deterministically per input. Duplicate identical prefixes share a single recorded call.

Population: all 231 public JevBench IDs, 64 reused v4 English cases, 62 unique prior policy cases (the known duplicated pair is removed first-occurrence by canonical input, independently of correctness), and 64 new harder generated English problems. New cases: 16 each of longer ledgers with distractor accounts, multi-stage schedules, alternating two-map pointer traversal, and interacting policies with balanced yes/no labels. Oracles independently checked in generation; seed 6230927. These are four authored families, not a broad external benchmark.

Exactly 41 archived drafts lack a valid terminal answer (40 public plus one reused English); these and 64 new tasks undergo new inference. The other 316 archived cases retain their exact old predictions. New tasks get live 160-token drafts and same-input baseline readouts. No evaluation labels enter prompts or routing. Full inference calls fail visibly on context/numeric/runtime errors; no case is silently removed or repaired using an answer key.

Model: Qwen/Qwen3.5-4B revision 851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a. Same BF16 backbone, FP32 categorical projection and pinned dependencies. Every worker verifies both weight-shard hashes, the full/restricted fixture and a native anchor. Old drafts were saved as text; continuation re-prefills a losslessly retokenized prefix, NOT the original KV cache or necessarily original tokenization. Even fresh continuation is re-prefilled for consistency; no cache-efficiency claim.

Primary endpoint: paired accuracy on 231 reused public tasks against Handoff160; fresh 64-task comparison is confirmation within the authored family. Report comparisons with the stronger earlier reasoning control and archived Jev 200/231 on matched IDs. Publish all arms and paired repair/regression counts, source-group bootstrap (public) and item bootstrap (fresh), conditional on these populations, without multiplicity correction. Generated labels get no invented probability distributions. Restrict any probability metrics to actual raw readouts and label them uncalibrated.

Compute: retain actual token IDs and durations per phase; count identical memoized branches once. Preserve old generation expense separately from new runs. Report re-prefill overhead and actual conditional paths, not a token-ceiling ratio as speedup. No 534-decision composite, hidden-set result, official submission, paid API calls, or Jev model/weight recovery is claimed.
