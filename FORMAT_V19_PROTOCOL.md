# Format v19 — matched representation training, September 24, 2026

Question: does varying source organization during otherwise matched event-distribution training improve transfer to a never-trained table representation? This is a causal data-treatment test, not a new architecture or a claim to invent augmentation.

Two fixed arms, three paired seeds19101/19102/19103. Single sees field-grouped prose on each scheduled world. Varied sees a deterministic, balanced assignment of prose, category-grouped records, or category-keyed JSON. Every corresponding update uses the SAME mathematical world, complete set of source facts (including irrelevant inventory), event target, answer label order, initialization, optimizer, and event-loss weight. Formats also change source ordering and token length; equal presentation/update counts are not equal tokens or FLOPs. No relational term, task mixing, generated rationale, oracle note, calibration target, or evaluation-driven routing is used in training.

Model: the unchanged pinned Qwen3.5-4B revision851bf6e806efd8d0a36b00ddf55e13ccb7b8cd0a plus rank4/scale2 FP32 factors on all32 MLP down projections (1,507,328 trainable parameters). AdamW lr1e-4, weight decay0.01, gradient clip1, loss0.5*target cross entropy,32 updates. Each update uses one event example; the unused modal-gradient branch from v17 is omitted identically in BOTH arms. This does not compare new timing/accuracy directly with archived v17 as if only formatting changed.

Data: seed1909242630;192 new generated worlds:128 fit-pool,32 calibration,32 test. Four mechanisms (counts, conditioning, mixtures, Bayes),2–5 categories, sharp/diffuse target strata, unique base modes. Each seed selects32 distinct fit worlds, one per mechanism/category-count/entropy cell. Varied renders each world once in its assigned format; it does not receive additional views or additional math problems. Baseline renders the same32 once as prose. All targets are exact independently calculable distributions. Held-out worlds are selected to distinguish a declared shortcut algorithm, so this is a challenge sample, not population-representative natural language. All variants of one world remain in the same split.

Evaluation:252 requests across seven states (unchanged plus all six final32 adapters), producing1764 new vectors. Includes32 canonical/noisy calibration requests;32 test worlds each in a2x2 matrix of prose versus entirely withheld Markdown table and irrelevant inventory absent versus present (128 requests);32 table/noisy replication variants;32 table/noisy relevant-count edits;28 historical external retention questions (first four sorted IDs from each of seven v18 BBH families, selected without inspecting model correctness). The retention set is a regression check, NOT fresh external confirmation. New probability worlds remain authored mechanisms and exact controlled grammar, not a broad independent language benchmark. The table format never occurs in any training or calibration input. No code-count extrapolation is claimed.

Primary endpoint fixed before any outputs: raw table+noise event target cross entropy AND squared-vector error, varied minus single, averaged over32 worlds and three seeds. Always report against unchanged and uniform, every arm/seed, all four representation/noise cells, interaction contrasts, and consistency/response-to-relevant-edit diagnostics. No best seed, early checkpoint or favorable alternative endpoint promotion. Report strict log loss from log-softmax; never replace full targets by their mode.

Apply unchanged to all event test cells. Raw primary is never replaced by the calibrated result, and unchanged gets equal calibration. Retention raw label accuracy and raw losses remain separate; do not assume event temperatures calibrate unrelated answers. Bootstrap10000 crossed paired-seed/within-family-world draws, keeping variants linked. Intervals are descriptive and do not correct for prior project exploration, multiplicity, uncertainty in fitted temperatures or unknown source dependencies.

Recovery: restart all six at paired initializations; do not resume old adapters. Save full parameters, optimizer/RNG states, next schedule index and complete ledger atomically after each real update. Retain snapshots8,16,32 without selecting on probe quality. Tests cover exact checkpoint resumption on a small CPU model and independent source/target equivalence. Real model checks and final completion receipts must also pass. Missing outputs remain failures; no silence, selective omission or unsignaled repair.
