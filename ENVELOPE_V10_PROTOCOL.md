# Envelope v10 — pre-outcome protocol, September 22, 2026

Objective: reduce silent English-to-formal meaning changes without pretending that proof checking verifies the parser. Extend Witness v9's restricted grammar to retain structural and opaque-name readings of coordination in relational complements, and narrow/wide readings of unmarked negated coordination. No ranked parse, model voting, weight training, or benchmark-label routing. A label is returned only when every fully enumerated supported interpretation has the same checked formal verdict. Unsupported syntax or interpretation-budget overflow abstains; truncating the set cannot produce an answer.

Each source clause retains its candidate interpretations. When verdicts differ, solve the finite minimum distinguishing-question problem: the smallest number of clause-reading selections such that opposite-verdict interpretations cannot remain in the same answer bucket. This is exact only for the enumerated envelope, not an optimal arbitrary English question or a claim that every natural reading was generated. Each formal verdict uses the v9 solver plus its separate Boolean certificate checker. Source parsing is still a shared trust boundary.

A separate caller-declaration mode treats explicitly supplied complete predicate phrases as unary atoms, consistently across their occurrences. Those declarations are semantic assumptions supplied by the caller, not inferred facts or verified language-model outputs. Generated alias tests provide the same original ontology under different spellings; their results must not be called natural-language inference gains.

Primary new audit: 2,000 normalized-input-disjoint examples from the original 14,200-item formal-fallacy source, excluding all 250 BBH source rows and both previously evaluated 1,000-item samples. Selection seed 109222026, independent of target keys. Compare Witness v9.2 and Envelope on exactly these same items. Report acceptance, source-label agreement conditional on acceptance, all disagreements, ambiguity and unsupported cases. No fresh neural fallback runs on these 2,000 items; do not report full hybrid accuracy. Same source generator means this is not independent-template generalization.

Secondary tests: 1,024 generated alias cases from eight fixed logical schemes, 32 spellings each, four styles (plain, and inside a name, or inside a name, operator inside a name). Independent truth-table target calculation. Compare old parser, undeclared envelope and explicit-atom envelope. These are ontology-preservation property tests with supplied semantic context, not 1,024 independent reasoning templates or a general model benchmark. The original 64-item neural baseline is reused only for a labeled historical replay. Public JevBench routing is inspected; no new neural JevBench score, hidden-set composite, calibration or production-speed claim.
