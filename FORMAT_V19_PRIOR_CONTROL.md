# Additional diagnostic: option-count-conditioned training prior

Declared before new Format-v19 model predictions are inspected. The training endpoint, primary, inference policy and evaluation population are unchanged.

For each seed and each allowed option count K, average the exact target vectors of that seed's 32 actual scheduled fit presentations having K options. This produces the empirical optimum for a constant per-K predictor under target cross entropy and squared-vector error. It never reads source facts, category names, test labels or calibration labels to fit parameters. The single and varied arms have identical targets and schedules of underlying worlds, so they share exactly the same control. No fitted smoothing coefficient, training algorithm, neural call, or code-position remapping is added.

Evaluate its RAW proper losses alongside the neural predictions on all four base event format/noise cells. All test cells of the same world receive the same vector. This is a stronger null than uniform allocation for distinguishing usable source information from a learned position/frequency prior. Its zero representation inconsistency is not evidence that it computes the actual problem. No correct-category tie is given an oracle treatment.

This is a secondary diagnostic, not a substituted primary or a baseline chosen for a favorable outcome. It is not calibrated on the test or applied to unrelated retention tasks with different label domains. Report all seeds and preserve the original primary varied-minus-single contrast, whether the new control helps or hurts the interpretation.
